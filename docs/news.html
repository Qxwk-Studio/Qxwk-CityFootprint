📢 公告

欢迎
欢迎使用 City Footprint！记录你走过的每一座城市，点亮属于你的足迹地图。
通行证
本站已接入青翔未阔通行证（account.qxwkstudio.top）统一认证：在本站登录表单里用通行证账号密码登录，注册、改密、邀请码等仍在通行证中心完成
颜色
每个用户拥有专属颜色（按注册顺序分配），地图上可多选筛选不同人的足迹。

📜 用户条款

关于数据
本网站的页面托管于 GitHub Pages，您的足迹、备注等数据存储于 Cloudflare 的境外服务器，数据安全性由相应服务商负责（只是一些行程数据也不需要什么保密吧）。使用本网站即视为您已知悉并接受这一点。如不同意，请勿使用本网站，并联系管理员删除您的数据。
地图来源
地图瓦片与行政边界数据来自第三方服务（高德地图、阿里 DataV），相关版权归其各自所有者所有。
免责声明
我们将尽力保障您的数据安全与服务的稳定运行。如因不可抗力导致网站停运（比如没钱运营了，但是10年之内应该不会发生的），我们会尽力通知您，并将您的数据交还给您。使用本网站即视为您同意自行承担相应风险，本站不对因使用本服务产生的任何直接或间接损失承担责任。
